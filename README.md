# BCTWU website
A responsive five-page website for the Bandaranayake College Gampaha Traffic Warden Unit. Plain HTML, CSS and JavaScript; no build step or dependencies.

## Run locally
From this directory run `python3 -m http.server 8000`. Open the local server in your browser.

## Edit on GitHub
- `content.js`: home page announcement cards.
- `index.html`: home page sections.
- `about.html`, `activities.html`, `safety.html`, `contact.html`: individual page content.
- `styles.css`: colours, typography, mobile layouts and animations.
- `app.js`: navigation and entrance animations.

Commit edits through GitHub's file editor. To deploy, use repository Settings → Pages → Deploy from a branch, select your published branch and `/ (root)`. No credentials or backend are required.

The design includes an animated loader, illustrated crossing, moving text, floating details, scroll reveals and hover interactions. Reduced-motion preferences are respected. Google Fonts are optional and have local fallbacks.

Before public launch, get school approval, verify all wording, add authorised contact details and replace the BC monogram with an approved school crest if desired. No events, officer names, or contact details have been invented. The activities page describes focus areas rather than claiming completed events. No contact form is included because no delivery service is configured.
